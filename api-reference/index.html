    API Reference¶

    Introspector¶

    PyramidIntrospector ¶

    Introspect a Pyramid application's routes and views.

    Discovers routes from Pyramid's introspectable registry and enriches them through a chain of extensions that handle library-specific metadata (Cornice services, pycornmarsh predicates, etc.).

    Parameters:

    Name Type Description Default
    registry Any

    A committed Pyramid registry.

    		 required
    extensions list[IntrospectionExtension] | None

    Optional list of extensions. When None, extensions are auto-discovered from built-ins and entry points.

    		 None

    introspect ¶

    introspect() -> list[RouteInfo]

    Discover routes and enrich them through all available extensions.

    Returns:

    Type Description
    list[RouteInfo]

    List of RouteInfo objects, each containing ViewInfo objects
    list[RouteInfo]

    enriched with library-specific metadata.

    Data Models¶

    RouteInfo dataclass ¶

    A route discovered from a Pyramid application, grouping its views.

    ViewInfo dataclass ¶

    A single view associated with a route, representing one HTTP method handler.

    ParameterInfo dataclass ¶

    A single parameter extracted from a route pattern or schema.

    SchemaInfo dataclass ¶

    A Marshmallow schema captured from introspection.

    SchemaFieldInfo dataclass ¶

    A single field in a Marshmallow schema.

    enrich ¶

    enrich(
    registry: Any, routes: list[RouteInfo]
) -> list[RouteInfo]

    Enrich route info with library-specific metadata.

    Extensions should mutate or replace the ViewInfo objects in the provided routes, adding parameters, schemas, and extra metadata.

    Parameters:

    Name Type Description Default
    registry Any

    The Pyramid registry.

    		 required
    routes list[RouteInfo]

    Routes discovered so far (may already be enriched by earlier extensions).

    		 required

    Returns:

    Type Description
    list[RouteInfo]

    The enriched list of routes.

    auto_discover_extensions ¶

    auto_discover_extensions() -> list[IntrospectionExtension]

    Discover and instantiate extensions from entry points and built-ins.

    Built-in extensions (cornice, pycornmarsh) are always included when their dependencies are available. Additional extensions can be registered via the pyramid_introspector.extensions entry point group.
